what is events ?
it is an action that happen in the browser ex., clicking button, moving mouse, pressing key, submitting form, loading page,
javascript detects these events and respond to them by executing a function, this is called event handling.

three types of events
1) mouse events
2) keyboard events
3) browser events

1) mouse events
- click: when an element is clicked
- dblclick: when an element is double clicked
- mouseover: when the mouse pointer is moved over an element
- mouseout: when the mouse pointer is moved out of an element
- mousedown: when the mouse button is pressed down on an element
- mouseup: when the mouse button is released over an element

2) keyboard events
- keydown: when a key is pressed down
- keyup: when a key is released
- keypress: when a key is pressed and released

3) browser events => load, resize, scroll
- load: when the page has finished loading
- unload: when the page is unloaded
- resize: when the browser window is resized
- scroll: when the user scrolls the page
- focus: when an element gains focus
- blur: when an element loses focus
- change: when the value of an input element changes
- submit: when a form is submitted
- reset: when a form is reset
- error: when an error occurs while loading an element (like an image)
